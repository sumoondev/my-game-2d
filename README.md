# my-game-2d

Hello everyone! This is my repository of my first 2d game.

I built this game using Godot 4.7 with the help of Godot documentation.

---

## How to play

Rules are simple:
1. **Move:** You can either use WASD or arrow key for movement
2. **Survive:** Try to dodge or avoid collision from the creeps 
3. **Score:** Score increases based on time, that is try to survive as long as possible

---

## Download and Installation

### Windows

1. Download `my-game-2d.exe`
2. Double-click `my-game-2d.exe` and play

### Linux

1. Download and extract `my-game-2d-linux.zip`
2. Make sure both `my-game-2d.x86_64` and `my-game-2d.pck` are extracted into the same folder.
3. Give the file permission to run. You can do this quickly via your terminal:
```bash
    chmod +x my-game-2d.x86_64
    ./my-game-2d.x86_64
```

### MacOS
1. Download `my-game-2d.dmg`.
2. Double-click the `.dmg` file to open it, then drag the game app into your **Applications** folder.
3. Open it up and enjoy!
